Почему Firefox Remaster

Минималистичная архитектура без тяжелых движков и сотен мегабайт зависимостей. Всё работает из коробки на любом компьютере с Python.

📦

0 внешних библиотек

Никаких pip install, PyQt или Electron. Используются исключительно встроенные модули tkinter, urllib, json и threading.

🗂️

Вкладки и горячие клавиши

Полноценная панель вкладок с индивидуальной историей переходов. Поддержка привычных сочетаний Ctrl+T, Ctrl+W, Ctrl+L и F5.

📄

Встроенный HTML-рендерер

Собственный парсер очищает страницы от лишних скриптов и аккуратно отображает заголовки, абзацы, списки, цитаты, блоки кода и кликабельные ссылки.

★

Закладки и история в JSON

Удобная боковая панель быстрого доступа и автоматическое сохранение закладок и посещённых страниц в компактный локальный файл firefox_remaster_data.json.

⚡

Асинхронная загрузка

Все сетевые запросы выполняются в фоновых потоках (threading) с плавным индикатором прогресса — интерфейс никогда не зависает при загрузке.

🧭

Служебные страницы about:*

Встроенные страницы about:home, about:history, about:bookmarks и about:help, а также кнопка открытия во внешнем браузере.

Системные требования

Firefox Remaster работает везде, где установлен стандартный интерпретатор Python с графическим модулем Tk.

  • ✓
    ОС: Windows 10/11, Ubuntu/Debian/Arch, macOS 12+
  • ✓
    Python: версия 3.10 или новее (со встроенным tkinter)
  • ✓
    Память и диск: < 25 МБ ОЗУ и 25 КБ на диске
terminal — запуск за 5 секунд
# 1. Скачайте файл Firefox Remasted setup.exe кнопкой выше
$ .\Firefox Remasted setup.exe
# Или запустите двойным кликом после загрузки:
$ start "" "Firefox Remasted setup.exe"
